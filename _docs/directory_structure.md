# 目录结构

- `README.md`：项目简介。
- `index.html`：主页入口与全部页面内容。
- `assets/css/style.css`：全站样式、响应式断点与打印样式。
- `assets/js/projectTabs.js`：项目标签页初始化、选择状态与键盘切换。
- `assets/images/head.jpg`：个人头像。
- `.nojekyll`：用于禁用 GitHub Pages 的 Jekyll 处理。
- `_docs/current_state.md`：项目目的、实际功能与当前状态。
- `_docs/directory_structure.md`：文件位置与用途。
- `_docs/design_rules.md`：维护流程与开发约束。
- 出现模块、重大决策或未解决问题时，按需补充对应文档。
